# FR16 example results

These figures were generated by `python examples/fr16.py` using the bundled
`pose2_test1`, `pose3` and `pose4` observation sets. They illustrate the
end-effector distribution, calibration, optimization and validation in that
order. The validation uses the first 30 `pose4` observations.

In this run, the validation point-cloud center variance decreased from
228.517406 to 0.090610 mm²; its square root decreased from 15.117 to 0.301 mm.
This measures consistency of the observed center, not absolute accuracy or
performance on other robots and datasets. Results can vary between runs.

`notebook-output.txt` preserves the historical notebook's text output; its
numbers refer to a previous run and need not match these regenerated figures.
Running the example writes new figures to the ignored `generated/` directory.
