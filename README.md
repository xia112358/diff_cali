# diff_cali

A small robot kinematic calibration project implemented with PyTorch.

The project uses a differentiable DH-based robot model and gradient-based optimization to calibrate kinematic and hand-eye parameters from repeated observations.

## Main components

- Differentiable DH / beta-parameter robot kinematics
- PyTorch autograd-based parameter optimization
- Hand-eye transform calibration
- Basic outlier detection and result analysis

This repository is a small engineering project rather than an actively maintained research codebase.
